Puretty Bridge

Lets local AI tools drive Krita: the krita_* tools of the libresprite-mcp server can create and open documents, add images as layers, look at the canvas, export it and run Python here, while you keep painting in the same window.

It listens on 127.0.0.1 only (port 8765, or the next free port; set PURETTY_BRIDGE_PORT to change it). Each Krita session writes its port and a random token to puretty_bridge.json in Krita's app-data folder; requests without that token are refused. The file is removed when Krita quits.

Tools > Scripts > Puretty Bridge Status shows the port it is using.

The run_python command runs any Python code inside Krita, like Krita's Scripter. Disable this plugin in Settings > Configure Krita > Python Plugin Manager when you don't want local tools to control Krita.
